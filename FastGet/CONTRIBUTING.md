# Contributing

Bug reports and pull requests are welcome.

1. Run `dotnet test tests/FastGet.Tests` before opening a pull request.
2. Add a test for engine changes. The tests use a local HTTP server, so they don't need internet access.
3. Keep each pull request to one change.

Please don't submit code copied or decompiled from closed-source download managers, or anything that bypasses DRM. Contributions are accepted under GPL-3.0-or-later.

To report a security problem, use GitHub's private vulnerability reporting instead of a public issue.
