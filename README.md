# Awesome Apps

A collection of open-source apps. Each app has its own folder, license, and releases.

| App | What it does | License |
|---|---|---|
| [FastGet](FastGet) | Download manager for Windows with Chrome integration | GPL-3.0-or-later |

[FastGet code signing policy](FastGet/README.md#code-signing-policy)

## Adding an app

Create a top-level folder with its own `README.md` and `LICENSE`. Add a row to the table above, and use tags in the form `<app>-v<version>` for its releases.
